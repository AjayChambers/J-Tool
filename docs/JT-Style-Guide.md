

## RULE GROUPS

### Characters & Character Widths
1. #### Indent Width
    - C++/C
        * Standard:          4
        * Continuation:      2
        * Ctor-Initializer:  2
        * Access-Modifier:  -2 (negative means offset)
    - MD    = 4 spaces
    - CMake = 2 spaces
    - JSON  = 2 spaces
    - YAML  = 2 spaces
    - Text  = 2 spaces

2. **TAB Character** \
    The tab character is not allowed. Indentation should be represented using the space char.

3. #### Column Width
    - C/C++ Code      = 90 chars
    - C/C++ Comments  = 65 chars
    - CMake Code      = 75 chars
    - CMake Comments  = 65 chars
    - JSON            = 120
    - All Other Types = 100
